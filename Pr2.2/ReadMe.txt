COMP141 Phase 2.2 - Parser (Python)

Files:
  scanner.py
  parser.py

Run:
  python parser.py input.txt output.txt

Description:
  • Scanner and parser for the Limp language as defined in PR2.2.pdf
  • Prints tokens, then AST in preorder (indented).
  • Stops and reports errors if a bad token or syntax issue occurs.

Requirements:
  Python 3.8 or newer
